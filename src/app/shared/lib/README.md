# shared/lib

Небольшая внутренняя библиотека. Каждая область — отдельный файл со своим фокусом:

- `id.ts` — генерация идентификаторов;
- `date.ts` — форматирование дат для интерфейса.

Сюда нельзя складывать «просто хелперы» и код с бизнес-логикой:
бизнес-логика живёт в `entities`/`features`, а не в shared.
